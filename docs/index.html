Adding It to Your Calendar

Each deadline appears as a half-hour block ending at the exact due time, with reminders two weeks, a day and two hours before.

Apple Calendar

Double-click the downloaded file and choose which calendar to add the deadlines to. On iPhone, open the file from Files or Mail.

Google Calendar

On a computer, open Google Calendar, then Settings, Import and export. Choose the file and the calendar to add it to.

Outlook

Double-click the file, or in Outlook on the web go to Add calendar, then Upload from file.

Questions and Answers

What is Duecal?

Duecal is a free, open-source bookmark that collects your Moodle assignment and quiz deadlines into one calendar file (.ics) for Google, Apple or Outlook Calendar, with reminders before each deadline.

How do I add my Moodle deadlines to Google Calendar?

Click the Duecal bookmark on Moodle and choose all modules. Then, in Google Calendar on a computer, open Settings, choose Import and export, and import the downloaded file into a calendar.

How do I add Moodle deadlines to Apple Calendar or my iPhone?

Double-click the downloaded file on a Mac and choose a calendar. On an iPhone, open the file from Files or Mail and add the events. If your calendars sync with iCloud, they appear on all your devices.

Will I get reminders before deadlines?

Yes. Each deadline has reminders two weeks, one day and two hours before it is due in Apple Calendar and Outlook. Google Calendar uses your calendar’s default notifications for imported events instead.

What if a lecturer changes a deadline?

Run Duecal again and import the new file. Each deadline keeps the same identifier, so Apple Calendar and Outlook update the moved deadline rather than adding a duplicate.

Does Duecal include Turnitin deadlines?

Only if your university also puts them in the Moodle calendar. Duecal includes every deadline Moodle’s calendar knows about.
